📦 base64 사진 → Storage 이관 도구

2026-07-15 사장님 승인 — 채팅·업무 데이터 안에 통째로 저장된 옛 사진(base64)을 Firebase Storage 로 옮기고 링크로 교체. 앱 로딩 속도 근본 개선. 오너 전용.

⏳ 인증 확인 중…
사용법 (2단계):
1️⃣ "스캔" — 옮길 사진이 몇 장·몇 MB 인지 먼저 확인 (데이터 변경 없음)
2️⃣ "이관 시작" — 한 장씩 Storage 업로드 → 성공 확인 후 링크로 교체
· 사진은 삭제되지 않고 위치만 이동합니다. 업로드 실패 시 원본 그대로 유지.
· 중간에 중지해도 안전 — 다시 열어 재시작하면 남은 것만 이어서 합니다.
· 사진이 많으면 오래 걸립니다. 탭을 열어두고 두세요 (폰보다 PC 권장).

1️⃣ 스캔 (변경 없음)
